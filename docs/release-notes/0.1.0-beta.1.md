Night Client 0.1.0-beta.1, the first public beta.

What you can do:
- Sign in with your Microsoft account (several accounts, kept encrypted on this PC).
- Create instances for Minecraft: Java Edition, plain or with Fabric or NeoForge.
- Find, install and update mods from Modrinth. Dependencies are added for you, and every file is checked.
- Let Night Client download the right Java automatically, or choose your own.
- Move the game data to another drive from Settings → Storage.

Good to know:
- This is a beta. Back up worlds you care about.
- Night Client is not an official Minecraft product and is not associated with Mojang Studios or Microsoft.
- There is no analytics or telemetry. Crash reports stay on your PC unless you export them from Diagnostics.

Found a problem? Use Diagnostics → Export… and attach the file to a bug report.
